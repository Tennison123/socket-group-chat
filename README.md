โปรแกรมแชทกลุ่มบนเครือข่ายเดียวกัน (LAN / Wi-Fi) เขียนด้วย Python และ CustomTkinter คนสร้างกลุ่มเปิดห้องบนเครื่องตัวเอง แล้วเพื่อนๆ ใช้ IP ของคนสร้างกลุ่ม เพื่อเข้าร่วม

✨ ฟีเจอร์
สร้างกลุ่มแชท และเข้าร่วมกลุ่มด้วย IP ของคนสร้างกลุ่ม

ฟองข้อความ มีรูปวงกลมตัวอักษรแรกและสีประจำตัวของแต่ละคน
แผงรายชื่อสมาชิกพร้อมจำนวนคน

ตรวจชื่อซ้ำในกลุ่มเดียวกัน
ปุ่มคัดลอก IP สำหรับส่งให้เพื่อน
📁 โครงสร้างโปรเจกต์
ไฟล์	หน้าที่
main.py	จุดเริ่มโปรแกรม ควบคุมการสลับหน้าและเชื่อมทุกส่วนเข้าด้วยกัน
server.py	ห้องแชทฝั่งเจ้าของกลุ่ม รับสมาชิก ตรวจชื่อซ้ำ แจกจ่ายข้อความ
client.py	ฝั่งสมาชิก เชื่อมต่อ ส่ง/รับข้อความ และออกจากกลุ่ม
protocol.py	ข้อตกลงรูปแบบข้อความที่ server และ client ใช้คุยกัน
utils.py	ฟังก์ชันหา IP ของเครื่อง
ui/login_frame.py	หน้าแรก (สร้างกลุ่ม / เข้าร่วมกลุ่ม)
ui/chat_frame.py	หน้าห้องแชท
ui/theme.py	ชุดสีและตัวสุ่มสี
requirements.txt	รายการไลบรารีที่ต้องติดตั้ง
🧠 หลักการทำงาน

โปรแกรมเป็นแบบ Client-Server ผ่าน TCP socket

  เพื่อน A ──┐
              ├──►  เซิร์ฟเวอร์ (เครื่องเจ้าของกลุ่ม)  ──►  แจกข้อความให้ทุกคน
  เพื่อน B ──┘
ข้อความทุกอันเป็น JSON 1 บรรทัด ต่อท้ายด้วย \n (รายละเอียดใน protocol.py)
เซิร์ฟเวอร์ใช้ 1 thread ต่อสมาชิก 1 คน และใช้ Lock ป้องกันข้อมูลชนกัน
ข้อความที่รับมาถูกใส่ใน queue แล้ว GUI มาหยิบไปแสดงทุก 100 มิลลิวินาที เพราะ GUI ห้ามถูกแก้จาก thread อื่น
เจ้าของกลุ่มก็ต่อเข้าเซิร์ฟเวอร์ของตัวเองเหมือนสมาชิกทั่วไป โค้ดแสดงผลจึงใช้ชุดเดียวกันได้
🚀 วิธีติดตั้งและใช้งาน

# 2. รันโปรแกรม

⚠️ ข้อควรรู้
เครื่องทุกเครื่องต้องอยู่เครือข่ายเดียวกัน (Wi-Fi หรือ LAN เดียวกัน) ถ้าต่างเครือข่าย ต้องตั้ง port forwarding หรือใช้ VPN เช่น Tailscale / ZeroTier
ถ้าเพื่อนเข้าไม่ได้ ให้ตรวจสอบ IP/พอร์ตให้ตรงกัน และอนุญาต Python หรือพอร์ตที่ใช้ใน Firewall ของเครื่องเจ้าของกลุ่ม
ถ้าเจ้าของกลุ่มออกหรือปิดโปรแกรม กลุ่มจะปิด และสมาชิกทุกคนจะหลุดทันที
ข้อความ ไม่ได้เข้ารหัส เหมาะกับใช้ในเครือข่ายที่ไว้ใจได้เท่านั้น
ยังไม่มีรหัสผ่านกลุ่ม การส่งไฟล์ หรือการบันทึกประวัติแชท
